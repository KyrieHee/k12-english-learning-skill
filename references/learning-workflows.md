# Learning Workflows

Use this reference for the internal modules: 学情诊断, 预习, 重点内容, 课堂同步, 专项突破, 考试, 错题本, 复盘, and 家长/老师反馈.

## Diagnosis Workflow

Before making a medium or long plan, diagnose:

- Grade/stage and textbook.
- Current score or class performance.
- Goal and deadline.
- Weak skill: vocabulary, grammar, listening, speaking, reading, writing.
- Weak question type: cloze, reading, grammar filling, translation, sentence transformation, writing, listening.
- Available time per day/week.

If the user provides an exam paper or mistakes, classify errors before planning.

Output:

- 学情画像.
- 主要短板.
- 优先级排序.
- 7-day or 4-week action plan.

## Preview Workflow

Purpose: make the next class easier.

Structure:

1. Topic warm-up.
2. New words: group by meaning and part of speech.
3. Phrases/collocations.
4. Core sentence patterns.
5. Grammar noticing, not heavy explanation.
6. Text prediction or listening/reading first pass.
7. 5-question self-check.

Time limits:

- Primary lower: 5-10 minutes.
- Primary upper: 10-15 minutes.
- Junior middle: 15-25 minutes.
- Senior high: 20-35 minutes.

## Key Content Workflow

Use a three-layer structure:

### Must Know

- Unit vocabulary.
- Phrases and fixed collocations.
- Core sentence patterns.
- Grammar point.
- Text meaning.

### Must Use

- Oral response.
- Sentence substitution.
- Short paragraph.
- Reading evidence.
- Listening detail.
- Writing task.

### Easy To Miss

- Similar words.
- Chinese-English transfer.
- Tense/person/number consistency.
- Preposition/collocation traps.
- Option comparison in reading or cloze.
- Writing rubric gaps.

## Lesson Explanation Workflow

For a textbook lesson:

1. State target in student-friendly terms.
2. Explain vocabulary in context.
3. Explain sentence patterns with substitution.
4. Explain grammar with contrast examples.
5. Read or listen for main idea and details.
6. Produce output: speaking or writing.
7. Assign short practice.
8. End with recall.

Keep explanations short. Use examples before abstract rules for younger students.

## Special Topic Workflows

### Vocabulary

Teach in groups:

- Topic group.
- Word family.
- Collocation.
- Confusable words.
- Example sentence.
- Retrieval card.

Avoid isolated word-list memorization unless the user specifically requests a list.

### Grammar

Use:

- Rule in one sentence.
- Positive/negative/question forms when relevant.
- Contrast examples.
- Common mistakes.
- 5-10 graded exercises.
- One output sentence or paragraph.

### Reading

Train:

- Main idea.
- Detail location.
- Inference.
- Word meaning in context.
- Author attitude.
- Evidence marking.
- Option elimination.

### Writing

Use:

- Genre and task analysis.
- Outline.
- Useful expressions.
- Model paragraph.
- Student draft revision.
- Rubric: content, structure, language, accuracy.

### Listening And Speaking

Use:

- Pre-listening vocabulary.
- Listening purpose.
- First listen for gist.
- Second listen for detail.
- Shadowing or role-play.
- Oral output with a simple rubric.

## Exam Workflow

Start with exam context:

- Exam type.
- Date or deadline.
- Target score.
- Current score and lost points.
- Question types.

Then build:

1. Score-loss map.
2. Priority weak points.
3. Timed drills.
4. Correction and retest.
5. Review schedule.

For each exam plan, include:

- Daily focus.
- Time budget.
- Question type.
- Scoring criteria.
- Retest method.

## Mistake Book Workflow

For each wrong question, produce:

- 原题类型.
- 错误答案 and correct answer, if available.
- 错因分类: knowledge, skill, process, or expression.
- 一句话规则.
- Similar example.
- Retest question.
- Review dates: +1 day, +3 days, +7 days, +14 days.

Mistake categories:

- Vocabulary: unknown word, wrong meaning, word form, collocation.
- Grammar: tense, voice, clause, agreement, non-finite, article, preposition.
- Reading: missed detail, weak inference, ignored evidence, option trap.
- Listening: sound confusion, speed, missed keyword, note-taking.
- Writing: off-topic, missing points, weak structure, grammar errors, simple vocabulary.
- Process: careless reading, timing, over-translation, no checking.

## Review Workflow

Use spaced retrieval:

- Day 1: redo from memory.
- Day 3: variant question.
- Day 7: mixed practice.
- Day 14: mini test.
- Day 30: unit integration.

Review outputs:

- What I remembered.
- What I forgot.
- What I can use.
- What needs another round.

## Parent/Teacher Feedback Workflow

For parents:

- Use plain language.
- Explain current level, progress, weak points, and home support.
- Avoid blame and excessive workload.

For teachers:

- Use precise skill/question-type language.
- Include evidence from mistakes or performance.
- Suggest intervention and assessment.

## Institution-Inspired Loop

When the user asks to combine tutoring institution styles, use this generic loop:

1. 诊断: find baseline and weak points.
2. 定标: set grade/textbook/exam target.
3. 精讲: explain one clear point.
4. 精练: short targeted drill.
5. 测评: timed or scored check.
6. 纠错: classify error.
7. 复盘: spaced review and next plan.

Keep this as a methodology, not as a claim about a specific institution's private syllabus.
