# k12-english-learning-skill
**k12-english-learning** 是一个面向中国 K12 学段学生的英语学习辅导 Skill，它基于国家课程标准、主流教材版本和教学机构常用的“讲练测评”闭环方法论，为小学到高中各阶段提供系统化的英语学习支持。核心能力覆盖四大模块：学情诊断（定位薄弱点与优先级）、教材同步（按人教版/外研版/译林版等版本匹配单元进度）、专项突破（词汇分组、语法对比、句型模板、听口训练）和测评复盘（限时训练、错题分类、间隔复习）。输出形式上，它能生成预习计划、重点知识梳理、单元测试题、错题本模板、一周复盘表和家长反馈，帮助学生把“认识单词”转化为“能做题、会开口、少犯错”的实际能力，同时让家长清晰了解孩子的学习状态和配合方式。
